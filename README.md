# 🏥 Sistema de Turnos Médicos - Entrega Final JavaScript

Proyecto final del curso **JavaScript (Coderhouse)**.

Este sistema permite registrar pacientes, seleccionar especialidades médicas, elegir doctores y reservar turnos con fecha y hora. Además, los turnos pueden visualizarse y cancelarse desde la sección **“Mis Turnos”**.

---

## 🧩 Tecnologías utilizadas
- HTML5, CSS3 y JavaScript
- Librerías: **SweetAlert2** y **Toastify**
- JSON local y **Fetch API**
- **LocalStorage** para persistencia de datos
- Manipulación dinámica del DOM

---

## ⚙️ Funcionalidades principales
1. Formulario de registro de paciente con validación.
2. Selección de especialidad y doctor.
3. Calendario interactivo de turnos.
4. Confirmación de turno con datos del paciente.
5. Gestión de turnos: ver, cancelar y liberar horarios.
6. Persistencia local con `localStorage`.

---
